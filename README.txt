MAKHANA ROOTS PRO — E-COMMERCE WEBSITE
=================================================
Six required pages:
- index.html — Home and About Us
- classic.html — Product Category 1
- flavoured.html — Product Category 2
- healthy.html — Product Category 3
- premium.html — Product Category 4
- contact.html — Contact Us and enquiry form

Included:
- Local product photography assets in /assets
- Responsive layout for phone and desktop
- Functional cart: add, increase/decrease quantity, remove items, subtotal
- Demo checkout form and order confirmation
- Contact enquiry form demo
- Shared navigation and styling

IMPORTANT:
This is a front-end college project/demo. Checkout does not collect money, payment gateway is not connected, and the enquiry form does not send emails. Product names/prices and contact details are sample data. Replace sample contact details before presenting if needed.

HOW TO PUBLISH FOR FREE USING GITHUB PAGES:
1. Sign in to https://github.com
2. Create a PUBLIC repository, e.g. makhana-roots
3. Extract this ZIP on your device.
4. Upload ALL files and folders inside the ZIP to the repository root (not the ZIP itself).
5. In repository Settings > Pages, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes and use the published link shown in Settings > Pages.
